## 3. 模块一：移动

### TC-MOV-001 — 方向键移动

| 字段 | 内容 |
| --- | --- |
| 优先级 | 高 |
| 前提条件 | 已选择可用存档并进入可操作的关卡；飞船已处于正常游玩状态。 |
| 操作步骤 | 1. 分别短按上、下、左、右方向键。<br>2. 分别持续按住四个方向键。 |

## 5. 模块三：存档记录、读取与独立性

| 优先级 | 高 |

| 状态 | 通过 |
| 完成日期 | 2026-09-29 |

### TC-SAVE-002 — 存档进度、累计生命使用记录与重进生命重置

| 字段 | 内容 |
| --- | --- |
| 优先级 | 高 |
| 前提条件 | 使用一个明确标记的测试存档；记录该槽位当前显示的关卡信息与 `Lives Used`。 |
| 操作步骤 | 1. 使用该存档进入游戏。<br>2. 完成一个会推进关卡进度的正常关卡。<br>3. 在后续关卡中记录一次或多次实际死亡，直至本局结束并返回主界面。<br>4. 正常退出游戏并重新启动，进入存档选择界面，查看该存档的关卡信息与 `Lives Used`。<br>5. 再次选择同一存档进入新一局游戏，观察右侧生命显示。 |
| 预期结果 | 重启后，存档槽位读取并显示更新后的最高关卡进度，以及本次实际死亡次数累计后的 `Lives Used`；它不保存上一局的剩余生命。再次进入该存档开始新一局时，当前可用生命重置为 3。 |
| 实际结果 | 实际执行结果符合预期。 |
| 状态 | 通过 |
| 完成日期 | 2026-09-29 |

## 6. 执行记录要求

- 每条用例执行后填写实际结果和状态，并记录执行日期。
- 出现失败时，优先记录实际现象、复现条件和 Evidence 文件；不要立即推断根因。
- 道具因随机出现而无法取得时，状态填写“阻塞”，并注明未出现的道具类型，不视为用例失败。

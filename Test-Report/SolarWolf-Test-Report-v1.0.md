## 2. 测试范围与方法

本周期聚焦四个核心模块：

1. 玩家移动与小方块交互；
2. 危险物、死亡与生命状态；
3. 特殊道具与计时器；
4. UI / HUD 与存档。

采用的测试方法包括黑盒探索性测试、功能测试、边界与状态转换测试、UI / 可用性测试，以及针对稳定逻辑的 pytest 白盒自动化测试。第一轮探索未查阅 SolarWolf 源码或 GitHub Issues；确认 UI 异常后才进行源码阅读与初步分析。

## 5. 已确认缺陷

| 缺陷编号 | 模块 | 严重性 | 优先级 | 状态 |
| --- | --- | --- | --- | --- |
| BUG-UI-001 | UI / HUD / 暂停与窗口焦点 | 高 | 高 | 已确认，开放 |

该缺陷在窗口焦点切换返回后可能导致右侧 HUD 未完整重绘，玩家无法可靠查看计时器和剩余生命。复现步骤、证据和初步源码分析见 [BUG-UI-001](../Bug-Reports/BUG-UI-001-Focus-Return-Incomplete-HUD-Redraw.md)。

## 6. 白盒分析结论边界

源码阅读显示，焦点切换后的暂停流程与局部脏矩形刷新机制，和 BUG-UI-001 的局部重绘现象相符。这是有证据支持的初步假设，不是已确认根因；本次测试未修改 SolarWolf 源码，也未验证修复方案。

## 7. 回归状态

本测试周期没有可供验证的 SolarWolf 修复构建，因此 BUG-UI-001 的“修复后回归”尚未执行，缺陷保持开放状态。当前版本的核心手工流程和自动化逻辑已完成验证；它们不等同于该 UI 缺陷已修复。

若未来获得修复版本，应使用 BUG-UI-001 的两条焦点切换路径进行回归，并重新执行 `python -m pytest Automation -q`。

## 8. 最终结论

本项目在受控范围内完成了手工测试设计与执行、探索性测试、稳定复现的缺陷报告、谨慎的 Python 源码分析，以及小范围 pytest 自动化。SolarWolf 的核心流程在本次已覆盖的测试条件下表现符合预期；但 BUG-UI-001 会影响关键 HUD 信息可见性，建议在后续版本优先处理。
